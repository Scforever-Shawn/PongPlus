# PongPlus 开发实施计划

基于极具创意的“卡帧停顿 + 精准反击”核心机制，我们设计了以下开发计划。这个机制非常有现代独立游戏（如《Lethal League》致命联盟）那种“拳拳到肉”的打击感（Game Juice）。

## 核心机制设计确认

**“爆燃火球”机制流程：**
1. **触发：** 道具定期在场中生成。小球撞击道具后，触发系统**卡帧停顿（Hit Pause/Freeze Frame）**。
2. **爆发：** 停顿结束后，小球获得**爆燃特效**（拖尾+发光），并以极高速度沿原轨迹冲向接球方。
3. **接球方判定：**
   - **精准反击（Perfect Parry）：** 玩家按下“反击键”（P1 按 空格，P2 按 Enter）启动格挡。
     - *视觉反馈：* 球拍瞬间变成蓝色，并闪过一道白色流光。
     - *判定窗口：* 从按下按键起，持续 **0.35秒**（适中的目押练习时间）。如果在这 0.35秒 内小球击中球拍，则判定为精准反击成功。
     - *成功结果：* 再次触发更长的卡帧停顿，小球以**更强的特效和极高速度**反弹给对手。
   - **普通接球（反击失败或未按键）：** 玩家接到了球，但未处于格挡状态，或格挡已过时。
     - *结果：* 触发“震碎”效果（屏幕震动+球拍粒子飞溅），球拍永久或暂时**变短**作为惩罚，小球回归正常速度反弹。
   - **未接球：** 对方得分。

## 系统架构与节点设计 (Godot GDScript)

为了实现上述功能，项目将拆分为以下主要模块（场景）：

### 1. `Main.tscn` (游戏主控)
负责统筹全局逻辑、比分、状态机和对战模式（PVP / PVE）切换。
- **UI 层：** 计分板，游戏结束提示。
- **摄像机 (Camera2D)：** 挂载一个屏幕震动（Screen Shake）脚本，在触发爆燃和碎裂时调用。
- **逻辑控制：** 监听得分信号，重置小球。

### 2. `Ball.tscn` (小球)
使用 `CharacterBody2D` 实现精确的运动学碰撞反弹。
- **状态机：** 正常状态、卡帧状态、爆燃状态。
- **特效组件：** `Trail2D`（拖尾效果，爆燃时激活）、`GPUParticles2D`（火花粒子）。
- **时间控制：** 包含一个 Timer，用于控制卡帧停顿的持续时间。

### 3. `Paddle.tscn` (球拍)
复用为 Player 1、Player 2 或 AI。
- **核心组件：** `CharacterBody2D`（用于移动） + `Sprite2D`（纹理） + `CollisionShape2D`（碰撞）。
- **动画控制：** 包含一个 `AnimationPlayer`，用于播放“精准反击时的蓝光闪烁”或“被震碎缩短时的形变”。
- **状态参数：** `is_parrying`，由 Timer 控制其 0.35 秒的有效窗口。

### 4. `Item.tscn` (道具)
使用 `Area2D`。
- 负责检测小球的穿过/碰撞。碰撞后通知 `Main` 或直接修改 `Ball` 的状态，随后播放销毁动画并消失。

## 开发阶段拆解

### 第一阶段：经典底座搭建 (MVP)
- [ ] 创建项目主结构和上述四大空场景。
- [ ] 实现 W/S (P1) 和 向上/向下 (P2) 的球拍基础移动。
- [ ] 实现小球的匀速移动、上下墙壁反弹、球拍反弹（根据击中球拍位置改变 Y 轴向量）。
- [ ] 实现简易 AI，使其能自动追踪小球。
- [ ] 跑通得分逻辑与重新发球机制。

### 第二阶段：道具与卡帧系统
- [ ] 实现 `Item` 的随机生成与倒计时销毁。
- [ ] 编写全局的“卡帧（Hit Pause）”功能。
- [ ] 实现小球吃道具后的状态切换（速度激增、附加拖尾节点 `Trail`）。

### 第三阶段：精准反击与视觉表现
- [ ] 在 `Paddle` 中加入“反击按键”与 0.35s 判定窗口。
- [ ] 增加球拍变蓝 + 白色流光效果。
- [ ] 编写 Normal 失败情况：球拍变短，触发碎裂粒子。
- [ ] 编写 Perfect 成功情况：再次触发卡帧，小球速度叠加，反弹。

### 第四阶段：手感打磨 (Juice!)
- [ ] 引入 `WorldEnvironment` 开启 Glow（发光泛光特效）。
- [ ] 实现 Camera2D 屏幕震动。
- [ ] 添加基础的像素/复古音效反馈。
